# Stable release 0.7.0

The homeowner approved 0.7.0 as the stable release on September 27, 2026,
replacing 0.6.1 (its record is kept as history). It brings together Beta
0.6.7–0.6.32; see `future_homes_tech_app/CHANGELOG.md`.

Installing this Stable version also applies what a Beta cannot: automatic
start with Home Assistant, the watchdog, the pinned base image, and the
optional GitHub access token option. `source_tree_sha256` covers the
`future_homes_tech_app` directory; archives are created on the development Mac.
