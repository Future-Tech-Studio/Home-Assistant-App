# Stable release 0.8.7

The homeowner approved 0.8.7 as the stable release on October 4, 2026,
replacing 0.8.4, which had replaced 0.8.1 earlier that day. It brings together
Beta 0.8.5–0.8.6 and the in-place Stable update button; see
`future_homes_tech_app/CHANGELOG.md`.

`source_tree_sha256` covers the `future_homes_tech_app` directory at commit
`ae46280` on `main`. The source and local-runtime archives were built in the
cloud with `scripts/package_candidate.py --local-only`; they are not in git.
There is no mounted archive yet, because the build was not checked against
the add-on share on the development Mac.
